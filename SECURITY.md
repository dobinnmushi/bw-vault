# Security policy / セキュリティ

**Reporting a vulnerability / 脆弱性の連絡**

Please do not open a public issue. Use this repository's **Security** tab → **Report a vulnerability** (GitHub's private reporting).
公開の Issue ではなく、このリポジトリの **Security** タブ →「Report a vulnerability」（非公開の報告）から連絡してください。

**Status / 状態**

This is experimental software that installs things as root, and it has not been audited by an independent third party.
See "Status" and "What it protects, and what it does not" in [README.md](README.md).
root で動く設定を入れる実験的なソフトウェアで、独立した第三者の監査は受けていません。[README.ja.md](README.ja.md) の「状態」と「守るもの・守らないもの」を参照してください。
